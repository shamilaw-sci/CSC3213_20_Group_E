# Private isolated browser fixture

Run from repository root with `RAYON_NUM_THREADS=1` and `node --max-old-space-size=512 docs/evidence/phase6-acceptance/visual-server.cjs`. Open `http://127.0.0.1:5175/__acceptance_host` through the authorized browser control. This fixture does not launch the browser or collect screenshots itself.

The 68 cases render original snapshot JSX and current production modules at 1100px and 390px in light and dark themes. Modules: AgentKpiCards, SellerConversationsPanel, BuyerAppointmentsPanel, ListingsOverview, PropertyCriticalDetails, HDPhotosSection, VirtualToursSection, ReviewPublishStep. Fixtures use controlled synthetic props and MemoryRouter. No auth, application API, environment configuration, maps, real uploads, or real payment is loaded. CSP restricts network origins to the local server; external Google font imports are blocked, so both sides use the same available local/system fonts.

Baseline source matches are checked before serving. `visual-provenance.private.json` records source paths and documented adapters. Agent retains original properties.length/pipeline expressions with controlled original-scope props. HD/tour prop renamings mirror the recorded extraction reconstruction proofs. Tour parent-owned rows are replaced with an explicit synthetic child slot, so the fixture covers the extracted shell only. Whitespace differences are allowed while locating original JSX; snapshots ignore whitespace-only text nodes. Styles and geometry are compared after fonts load and animations settle. Geometry is rounded to hundredths of a pixel.

Run all cases writes `visual-comparison.private.json`. Each row includes actual equality, element counts, up to three differing element snapshots, captured runtime errors, and post-action comparison/events. Actions include favorite toggle, owner navigation, admin search/filter, buyer booking navigation, seller inbox navigation, review edit, and controlled photo/tour change callbacks. The case selector and separate action button allow native focus/click inspection. Additional action reports append to `visual-interactions.private.jsonl`.

This is sampled extracted-module browser acceptance, not complete page acceptance. Excluded: full routed-page shells, live auth/API flows, maps and Leaflet, actual media upload processing, actual payments, original tour row logic, modals, every unsampled extracted module, keyboard navigation audits, and all responsive widths beyond the two recorded widths. Never report this fixture as exhaustive browser coverage. Browser execution and visual review remain required before claiming results.

The first browser run's report is retained as `baseline-failure.private.json`. Its eight Admin interaction mismatches arose because snapshotting both frames after focusing the second frame compared different focus states. The corrected runner captures each frame immediately after its own action, before the other frame receives focus, and records active-element and focus-visible metadata. It preserves the actual focus styling in both snapshots.
